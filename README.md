# Universal Manual

계층형 매뉴얼을 작성하고 찾아보는 브라우저 프로그램입니다. 문서 본문, 표, 이미지, 재사용 참조값을 관리하며 읽기 모드와 수정 모드를 제공합니다.

**[웹에서 실행](https://nas306.github.io/Universal_Manual/)** · **[v3.1 기술 문서](Universal_Manual_v3.1.md)**

## 시작하기

웹 버전을 열거나 저장소의 [index.html](index.html)을 내려받아 브라우저에서 엽니다. 서버 설치, 빌드, npm 의존성은 필요하지 않습니다. 기술 문서에 등장하는 `Universal_Manual_v3.1.html`의 현재 저장소 파일명은 `index.html`입니다.

1. 좌측 상단 메뉴에서 작업본을 선택하거나 복사합니다.
2. 수정 모드에서 제목, 안내문, 계층형 항목과 표를 편집합니다.
3. 읽기 모드에서 내용을 확인하고 검색합니다.
4. 중요한 변경 후에는 메뉴의 JSON 내보내기로 별도 백업을 저장합니다.

수정 모드의 `Ctrl+Z` 또는 macOS `Cmd+Z`는 현재 세션에서의 변경을 되돌립니다. 작업본 전환·불러오기·새로고침 후까지 되돌리기 이력이 유지되는 기능은 아닙니다.

## 저장과 백업

내용은 브라우저 `localStorage`에 저장되며 JSON으로 내보내고 불러올 수 있습니다. 계정이나 서버 동기화 기능은 없습니다. 브라우저·프로필·실행 주소를 변경하면 기존 저장 내용이 보이지 않을 수 있으므로, 파일 실행과 웹 버전 사이를 이동할 때도 JSON 백업을 사용하세요. 사이트 데이터 삭제 전에도 백업이 필요합니다.

## 유지보수

현재 저장소에는 별도 소스 모듈이나 `build.js`가 없으며 실행 파일 자체가 소스입니다. 이번 문서 정리에서는 프로그램 구조나 기존 JSON 형식을 변경하지 않았습니다. 향후 기능을 수정할 때는 역할별 소스를 분리하고 `build.js`로 단일 HTML을 생성하는 구조로 전환하며, 모듈 이름과 빌드 방법을 이 문서에 기록합니다.

기존 파일을 변경하기 전에 `파일명_BU.확장자` 백업을 만드세요. 데이터 구조 변경 시에는 예전 JSON을 계속 읽을 수 있는지도 확인해야 합니다.

현재 자동 테스트는 없습니다. 수정 후에는 작업본 생성·전환, 본문·표·이미지 편집, 검색, 참조 치환, JSON 내보내기·재불러오기와 새로고침 후 복원을 확인하세요.
